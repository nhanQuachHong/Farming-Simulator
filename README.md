# Farming-Simulator

Dự án game nông trại 3D trên Roblox. Bản khởi tạo gồm một Baseplate 256 × 256 studs và điểm xuất hiện ở giữa bản đồ.

## Chạy thử trong Roblox Studio

1. Đăng nhập Roblox Studio và mở `Farming-Simulator.rbxlx` bằng **File → Open from File**.
2. Chọn **Play**. Kiểm tra avatar xuất hiện ở giữa, đi được trên nền và có thể nhảy.
3. Chọn **Stop** để trở lại chế độ chỉnh sửa.
